# hingesemver

Hinge lightweight semver statistics from stdin samples.

**Site:** https://theworker02.github.io/hingesemver/

## Install / run

```bash
git clone https://github.com/theworker02/hingesemver.git
cd hingesemver
node src/cli.js
node --test
```
